## 2026-09-20 · 第一次在真实分布上量：可读性达标，事实准确度不达标

两件此前没做的事，把上一节的结论改写了：

**一、把成稿摆给读者读。** 判定是：原型像「结构化信息汇编」，生产那版信息少但是「高管简报」，
要后者。而通过线里的核心层覆盖率恰恰奖励前者 —— 两代加长与「必写」改动是朝错方向优化
（见 `lesson-coverage-metric-pushes-listing`）。据此把写作改成 **exec 档：3–5 句、每句综合一组事实、
结论先行、意义只在原文有人明说时写**。

**二、在不挑选的一整天上跑**（`prod-0919`：2026-09-19 当天 selected_for_intel 的 25 簇 818 篇，k=3）：

| 读数 | 值 |
|---|---|
| 路由门拒掉 | 8/25（32%），人工核标题确认**拒得对**，全是杂项堆 |
| 快档（零 LLM） | 51 篇 248 句全绿：数字缺出处 3、引语 1、块内重复 7 对 |
| **读者可见的错** | **16/248 = 6.5%**（编造事实 8、编造关系 8） |
| 出处挂错（事实真、被引那句撑不住） | 55/248 = 22% |
| 整篇有读者可见错或混写 | 20/51 = **39%** |

**结论：还不能上线。** 每 3 篇就有 1 篇以上至少一句问题，其中包括「22 名平民死伤」被写成
「22 名美军阵亡」这类读者会当真的错。此前在 7 簇手挑集合上从没量准过
（见 `lesson-handpicked-fixtures-dont-extrapolate`）。

**配套把 eval 重构成模块**（ADR 0006、`eval/cluster-to-brief/CONTRACTS.md`）：
dataset 可版本化且标注挂在输入上、判据只描述输出性质（`noEventMixing` 取代「必须拆 ≥2 块」）、
评分与生成分离、判官有六轴规格与落盘验收闸、默认 k=3 报均值与极差。

**下一步按顺序**：
1. 标一批 gold，把 `citation-support` 判官与人工对齐（没对齐的比例不能进对比表）
2. 单变量实验：换写作模型，冲 6.5% 这个数
3. 把机械补出处从数字/引语扩到专名与从句，冲 22%
4. 之后才是迁移：v6 做成 ai-worker 端点（输出契约加 `quote`）→ 接 Workflow → DB 与前端

## 2026-09-19 · scorer 重建与第一条 Pareto frontier（`eval/cluster-to-brief/`）

**这一轮是问题层搜索，不是实现层。** 判据改了，按 CONTEXT.md「判据变了旧读数作废」，
**此前全部实现层读数作废** —— 包括写进知识库的「逐句接地把硬错从 5 压到 1」那条归因。

**改了什么**
- 事实证据由脚本从整簇检索 top-8（本地 e5-small，零远程调用），**与成稿引了谁无关**。
  旧做法把窗口锚在成稿引的那一句上，引得宽的臂天然拿到更多证据 —— scorer 量的成了引用行为
- 新增 `citedSentenceSuffices`（被引那句本身够不够）与块内冗余（同块两句引同一条原句），都只报不设门
- 事件清单去杂质（零 LLM）：此前分母里混着只有杂质文章报道的事件，**正确剔掉杂质的臂反而被扣分**
- grading instructions 补「消息源剥离」一档：剥掉「X 说 / 据 Y」不算合理省略
- 判定包与尺各算一个指纹，尺一改旧判定自动隔离并 exit 2（`scorer-id.mjs`，自测 9 个边界）

**量到的**
- 两判官不一致率 **18% → 0%**（c43 两臂各两判官，63 句），引用维 Jaccard 1.0 / 0.8
- 判官检出能力首次有数：82 句自然金标上**召回 12/15 = 80%、精确率 86%**（上一代 20%/33%）。
  同分布定向抽查 32 句，零确认漏判
- 补「消息源剥离」之前 fatal/hard 在所有格子上**全是 0**（正确性那道门形同虚设），补完立刻分得出臂
- dev 五簇五臂盲判：`direct-raw-routed` **被 `direct-raw-routed-storyline` 支配**，第一个被明确淘汰的臂

**推翻的两条**
1. 逐句接地的优势不是「写得对」，是「引用标得准」（引用不足 14.8% vs 27.6%），覆盖代价 76.2% 是真的
2. 「主线筛选压制乱安来源」在三簇上是 3:1，补到五簇变成 4:3 —— 差距基本消失

**卡在哪**：dev 只有 5 个簇，且七簇全部来自同一次生产运行（2026-09-15），不是独立抽样；
heldout 两簇已消耗。n=5 的配对符号检验只有 5:0 全胜才到 p<0.05，
**6 个百分点的差距不构成证据**。扩样本的瓶颈不在判官成本（零 API、十分钟一轮），
在于每个新簇要人工按标题标杂质、且重跑各臂需要可用的 LLM key（DashScope 目前 401）。

**下一步候选**：把引用质量机制接到 `routed-storyline` 上做一次 crossover（供体优势已在新尺归因）；
或先扩 dataset 到 12–15 个跨日期簇并重划 heldout。
