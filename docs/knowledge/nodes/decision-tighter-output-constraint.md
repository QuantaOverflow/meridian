批大小不变（20 句），只在抽取 prompt 末尾追加一条更严的产出约束。满覆盖对照实测：

| 簇 | neurons/句 | completion_tok/句 | 召回 |
|---|---:|---:|---:|
| c18 | −19% | −40% | 20/30 → **22/30** |
| c0 | −8% | −19% | 12/13 → **13/13（满分）** |

越界引用 0 条。输入 token/句因为多了约束文字涨 8–11%，但输入占比小，不影响总账。

**这是目前唯一「省钱且不伤质量」的杠杆**，但落到整份报告的口径上，省的没有 spike 说的多。

## 同日第二次跑（带 inline 观测做分步归因）：**省的钱是噪声**

| 跑次 | 四簇合计 neurons |
|---|---:|
| 基线（无 L2） | 2397.8 |
| L2 第一次 | 2246.4（−6.3%） |
| L2 第二次 | 2415.1（**+0.7%**） |

两次一降一升，跨过基线——**L2 在整份报告口径下省不了钱**，第一次的 −6.3% 落在已知的 ±5% 跑间波动里。
（两次跑唯一差别是第二次带 `x-observe: inline`，观测只记录不改 prompt，不影响成本。）

分步归因（基线 → L2 第二次）：

| 步 | neurons | 输入 tok | 输出 tok | 调用 |
|---|---|---|---|---|
| extract | 1177.8 → 1184.0（**+0.5%**） | 82,135 → 89,163（**+8.6%**） | 19,948 → 19,054（**−4.5%**） | 75 → 74 |
| dedup | 817.7 → 799.2（−2.3%） | 100,423 → 98,026 | 7,290 → 7,145 | 125 → 121 |
| voices | 402.2 → 431.9（+7.4%） | 52,648 → 52,648（一字不差） | 3,095 → 3,909 | 6 → 5 |

**机制已闭合**：约束确实让模型少写字（输出 −4.5%），但约束文字本身让输入涨 8.6%，两者相抵净 +0.5%。
代进换算公式 `7,028×0.00545 − 894×0.0364 = +5.8`，实测 +6.2，对得上。
spike 报的 completion/句 −19~40% 在整报告口径下只剩 −4.5%——**spike 的 per-sentence 口径高估了真实收益**。

**留不留**：留。质量侧两次一致地不伤（M1 ALL PASS、越界 0、c0 召回 13/13、c18 20/30→21/30、
骨架合计 62→65），且不花钱也不省钱。要撤只需删掉 `OUTPUT_CONSTRAINT` 的拼接。
**但它不能用来补 $10.20 的成本缺口**——真正的入口见 measure-dedup-fixed-overhead。
