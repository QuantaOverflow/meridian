# block-merge-v1 标注规范：一期简报里「同一件事出现在多块」

单位：一期（一次定时简报）里的入选故事，每个故事写成简报里的一块。只在**同一期内**判，不管跨期重复。

## 四种标签

| kind | 含义 | 该怎么修 | 计分 |
|---|---|---|---|
| `same` | 几块讲的是**同一件具体的事**（同一次会面 / 访问 / 讲话 / 袭击 / 判决 / 灾害 / 抗议），只是时刻或角度不同 | 合成一块 | 没合 = 剩余重复；合了别的 = 合错 |
| `spill` | A 块的某几句讲的是 B 块那件事（A 的主体是别的事） | 删掉 A 的那几句（合并也能消掉重复，但会造出一块两件事） | 没删也没合 = 剩余重复 |
| `tail` | A 块的某几句与本块无关、也不对应本期别的块 | 可删 | 删了加分，不删不扣分 |

没有标签的故事对一律视为**不同的事**。

## 判「同一件事」的规则

来自用户（2026-09-27 亲标与事件追踪那轮定的分组规则）：

- 同一次访问的不同环节算一件：教宗访法的卢尔德一站与巴黎弥撒（用户标）；习近平访美的抵达、峰会、国宴、赠熊猫。
- 同一天同一场冲突、内容大量重叠的两块算一件：俄乌同日两块，都写空袭、拉夫罗夫、特朗普盼「和解」（用户标）。
- 一次讲话与针对这次讲话的抗议算一件；同一天同一场合、同一对当事方的讲话与会谈算一件（特朗普联大讲话威胁伊朗 + 场边美伊会谈）。
- **话题相同不等于同一件事**：同在联大发言的不同领导人（内塔尼亚胡 vs 阿巴斯）、同是特朗普但不同场合（联大讲话 vs 封杀媒体 vs 习近平峰会），都是不同的事。
- **同一方的同类事算一件**：南非两起枪击与连环杀害女性案；尼泊尔洪灾与雪崩；美伊之间同一天的拒停火与扣押无人机之争；泽连斯基在联大的会谈与演讲。
- **后果并进大事**：英国为沙特战机加油并进也门战事；英国暂停查戈斯付款并进特朗普–伯纳姆会面；选举日的无人机袭击并进俄议会选举。
- 同一场合同一天、但当事方不同（伊朗总统访联大 vs 特朗普联大讲话）：不同的事。

## spill 与 tail 的句号

`sentences` 是该块按句切分后的下标（0 起），切句结果就是 `evidence.jsonl` 里的 `block_sentences`。
只标讲的明确是另一件事的整句；一句里一半讲本事、一半讲别的事时，看主干讲的是什么。
