# story-threads-v1：事件追踪故事线金标（主集）

考的是**事件追踪的线索归并**：把各期简报里的故事归成跨期线索，该并的并、不该并的分开。

## 单位与标签

- 一行 = 一个进了已发布简报的故事（`brief_stories`，`selected_for_intel = true`）。
- `line` = 这个故事归属的**故事线**（读者在「事件追踪」里点开、按日期看的一条线索）。同一 `line` 的故事应在同一条线索里。
  只出现一期的故事各自一条 `s<story_id>` / `c<cluster_id>`。
- `unsure = true`：归属拿不准，**算分时整条排除**（既不当评测对象，也不进任何一边的组）。
- `period`：按发布时间排序的期序号。评测必须按期在线回放：处理第 p 期时只能用第 1..p 期。

## 分组规则（用户定，2026-09-28 / 09-29）

1. 粒度跟着读者会追的大局走：整场俄乌战争是一条，不按单次袭击拆开。
2. 同一方干的同一类事算一条：朝鲜服役新驱逐舰和试射导弹是一条；俄罗斯在欧洲的无人机袭击、军火库、破坏、暗杀阴谋是一条；
   巴基斯坦开普省的两起自杀袭击是一条。
3. 一件大事引出的后果并进这件大事：加拿大因贸易战靠拢欧盟并进美加贸易战；伊朗战争带来的美国油价、通胀并进美伊战争；
   加沙战争引起的国际诉讼、通缉令并进加沙战争；美国国会限制对伊朗动武的决议并进美伊战争。
4. 一个政策领域可以单独成一条（特朗普收紧移民：签证、H-1B、出生公民权、ICE 执法是一条），
   但不能把一个政府的所有政策或事件并成一个主题。
5. 话题相同不等于同一条：两起不相干的枪击案、两场不同的峰会（上合与金砖）、两场不同的台风各是各的。
6. 同一场活动的前后环节算一条：世界杯小组赛与淘汰赛；一场选举的初选各场决选；访问的筹备与会谈。
7. 天气：同一片区域同一个季节的热浪与干旱算一条（欧洲热浪与干旱）。

「值不值得追」不在这份金标里判：用户 09-29 决定先放宽（出现 ≥2 期都展示），靠读者反馈再收紧。

## 评测窗口（不是 split）

整份数据集的 split 是 dev（已耗尽）。每行的 `window` 只是评测窗口，因为线索归并是在线的，
评后半段时前半段必须作为上下文一起回放，所以不能拆成两份数据集：

- `window = dev`：第 1–19 期，调参用过多轮。
- `window = holdout`：第 20–38 期。**已被看过错例**（2026-09-29 那轮原型比较），只作参考。
