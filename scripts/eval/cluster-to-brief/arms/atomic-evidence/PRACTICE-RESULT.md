# 核验层 60 题扩展练习结果

2026-09-17。结论：当前枚举槽与显式词选槽没有提供净收益，不接入组合链路。核验层问题尚未解决。

## 材料和路线

`gold/practice-risk-v1/`：五个 dev 簇各 12 题，30 正常、30 人工错误变体，32 个参考错误片段；30 对照组、18 事件组。当前 Codex 阅读冻结原句给出非盲、单标注参考判断。没有自然错误率、显著性或泛化结论，未读取 heldout 正文、清单或 arm 输出。

- 整句对照：本轮新建的简短完整支持核验，非旧版 atomization+gate 的重跑。每题一个整体支持判断。
- 模型槽：候选 → 模型固定类别/精确 span → 代码模板 → 逐槽核验。第一批规划缺时序、数量并添加假归因；第二批两次规划均违反精确 span 契约，停止。只调用第一批四题的下游，不能报告 60 题该路线成绩。
- 代码槽：以通用英文显式词触发归因、时序、数量、模态、动作、因果检查，另加完整支持兜底。没有实体、簇号、题号特判，无模型规划调用；此规则版本冻结后跑全 60 题。

两完整路线同模型 `@cf/zai-org/glm-4.7-flash`、同冻结证据、同混排和 opaque item id。Workers AI 仅作被测功能；没有远程 judge。参考答案、风险标签和人工问题不进入模型输入。通常 temperature=0，契约失败第二尝试为 0.1。不同输出重试路径也可能影响成绩，本轮没有单独标定其影响。

## 共同有效材料上的比较

各路线都运行全部 60 题；输出契约失败时逐题保留末次仍有效的结果，其余 unavailable，不再修改答案或继续语义重试。整句对照有 58 题可用，代码槽有 55 题可用；共同有效 54 题，其中 28 个错误父句含 29 个参考错误点，26 个正常题。

| 指标 | 整句对照 | 代码槽 |
|---|---:|---:|
| 具体原错误仍被放行 | 3/29（10.3%） | 7/29（24.1%） |
| 错误父句被放行 | 3/28 | 7/28 |
| 正常题被语义拒绝 | 0/26 | 0/26 |
| 全 60 题最终契约失败 | 2/60 | 5/60 |

这些输出不拆原子、不改写、不保留局部安全原子：只放行或拒绝原整句。因此整句拒绝会删除其全部原错误；逐错误指标表示错误是否仍被放行，不表示拒绝理由逐一准确诊断了错误。

未配对的完整可用结果：整句对照漏过 3/31 个错误点、误杀 0/29 正常题；代码槽漏过 7/29 个错误点、误杀 0/27 正常题。不同可用分母不能直接当改进趋势。

契约失败题：整句 p01-u、p16-s；代码槽 p18-u、p22-s、p01-u、p08-s、p02-s。若实际 fail closed，前者还会挡掉一条正常题，后者挡掉三条；所以“语义误杀零”不等于正常内容零损失。

## Codex 原文核对的错误与变化

共同漏判：

- p11-u：原文 Meink 说话、记者听取；候选改成记者说话。两路线都找到相关句，却没核对 speaker/recipient 关系。
- p12-u：原文 analysts warn will accelerate，候选为 confirmed had already accelerated。代码槽的 modality check 仍把 warn 当成 confirmed 的支持。
- p20-u：562 是 damaged areas 总数，只有部分元素 completely destroyed；两路线都因两个词在原文出现而支持 562 全部毁坏。

代码槽新增漏判：p14-u（Bahrain 不参加变参加）、p21-u（政变后变政变前）、p29-u（移除回放变永久取消节目）、p08-u（空军部长变国防部长）。没有共同有效题由整句漏判变成代码槽正确拦截。

原文精确引用只是契约：例如引用包含 After the coup，候选和检查锚点是 Before，模型仍说支持。引用能解析并不意味着主体、方向、状态或数量归属对齐。

## 成本与验证

已记录 51 次 HTTP 响应：54,649 input / 31,877 output tokens，累计请求耗时 876.61 秒。不是总体墙钟，也不是美元账单：

- 整句对照 22 次，16,947 input / 12,278 output，250.35 秒。包括最初长输出诊断失败与恢复时 b11 重复失败。
- 模型槽 6 次，5,176 input / 2,956 output，72.97 秒。
- 代码槽 23 次，32,526 input / 16,643 output，553.29 秒。

还有一条早期在途请求被中断，没有返回 usage，未包含在以上已知 tokens/耗时，实际计费未知。远程 binding 偶发 internal error，服务重启一次；无基础设施错误计入语义拒绝。

新接口及旧 risk/auto-risk 契约检查共 9 项通过；fixture 结构检查通过。`pnpm typecheck` 退出 0（四项 Turbo 缓存命中），不覆盖新 mjs 语义，也不代表 gate 达标。`practice-review.mjs` 实际运行生成逐错误记账。没有 commit、部署或生产链路修改；本轮服务已关闭。

产物：`out/atomic-evidence/practice-v1/` 的 mapping、批次结果与 raw、calls.jsonl、两路线 summary、local-review.json。重新运行同版脚本复用缓存；复用缓存不是独立复测。

## 下一轮缺口

typed category + 薄词锚点不足以约束候选与证据的关系对齐。第一匹配词也不能定位复合句里的全部同类风险。优先检验能否得到绑定了角色和作用域的值或关系，例如 speaker→proposition、event pair→direction、count→population/state、proposition→epistemic state，再比较候选与证据；不能只问某词是否出现。该表示尚未实现或验证。

保留较简单整句对照作实验起点，暂缓把失败槽路线融入组合。不宣称 prompt 或架构因素已被严格区分，也不推论所有风险槽方案无效。下轮仍可用练习材料设计，但最终需冻结后另取独立材料；本轮没有建立独立验证集或跑端到端组合。
