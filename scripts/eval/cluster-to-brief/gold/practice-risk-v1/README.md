# 核验层练习集 v1

2026-09-17。针对长期反复使用 c36 八例的问题，扩展到五个 dev 簇的 60 道练习题。

## 内容与使用

- `inputs.jsonl`：只有候选、来源坐标和冻结原文，没有参考答案、风险类别或人工核验问题。送入自动链路时仅使用此文件；候选 id 不应传给模型，因为后缀暴露正负标签。
- `labels.jsonl`：Codex 逐原文阅读后的支持标签、具体错误片段、理由、配对及事件组。只供调优分析与评分，不能作为自动风险定位器输入。
- `PRACTICE.md`：人读版本，展示对照题、证据与解释。
- `manifest.json`：数量、来源、评测边界与限制。
- `check.mjs`：零网络核对来源、冻结证据哈希、错误片段、标签对应与计数。

检查命令：

```sh
node scripts/eval/cluster-to-brief/gold/practice-risk-v1/check.mjs
```

每簇 12 题，共 30 个对照组：30 条得到证据支持的人工表述、30 条人工错误变体，含 32 个显式错误片段。覆盖主体身份、命名对象、动作强度、归因、时序、数量、模态和因果。来源为当前本地 fixture 正文，使用 `lib.mjs` 的标准句号坐标。未读取 c28/c51 正文、清单或输出。

## 标注口径

支持性只相对于提供的证据包，不表示全球事实真伪，也不评估候选是否应入该簇简报。c37/c43 中不同事件各自的事实可以得到支持；簇形态和选题相关性由其他职责处理。

有归因的候选核验“谁说了什么”，不要求被转述命题必须独立为真。未被证据支持的细节与被证据反驳的细节都标 `unsupported`；错误理由保留区别。候选不是原文逐字复制，正常题也含概括、组合和归因作用域。

大部分对照改变一个风险维度；p18-u 的救援完成状态含两处错误，p26-u 的数量互换也含两处错误，已逐个标出。评分必须逐错误片段检查是否仍被放行，不能用“整句至少拒绝一项”代替逐错误检出。

## 能做与不能做的结论

这是人工分层编写的行为练习，不是随机抽取的自然模型错误集。正常题为 Codex 人工表述，错误题为其变体；没有新生成模型候选，也没有评测任何 gate。零远程模型调用。

标签来自当前 Codex 的一次非盲原文阅读，没有第二独立标注者或泛化保证。结构检查通过仅表示数据可定位和契约一致，不证明语义标签绝对正确。

60 题仅有 30 个证据对照组、18 个事件组；c7 的 12 题全部来自同一个事件。同对照组不能随机拆到调优和验证两侧；即使不同文章，也应至少按 `eventGroupId` 分组。此集合全部属于 practice，不用于报告独立准确率、显著性或真实错误发生率；最终 heldout 仍保留。

下一步在本练习集上分析失败类型；独立验证需要另取没有参与修改的新材料并冻结方案。尚未建立独立验证集。
