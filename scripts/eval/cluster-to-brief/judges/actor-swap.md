# judge: actor-swap（主体搬错）

一轴一份规格，本文件自足：读完它 + 指令点名的文件就能判完，不需要再看仓库里任何别的东西。
本文件的哈希就是 `promptId`。**改本文件等于换一把尺，旧判定作废**（`collect-verdicts.mjs` 拿退出码拦）。

## 判什么（二元）

对成稿的每一句：**这句话把某个动作、表态或引语挂到了错的一方身上？**

`fail` 的典型形状：

- 动作换人：原文是 A 部署 / 发射 / 批准，成稿写成 B 做的。
- 表态换人：原文是 A 说的，成稿写成 B 说；或写成「双方」「官方」而原文只有其中一方说过。
- 引语换人：引号里的原话确实在簇内，但说话人被换了。
- 受动方与施动方对调：原文 A 制裁 B，成稿写成 B 制裁 A。
- 国家/机构层级搬错：原文是某部门，成稿写成整个政府；原文是某公司子公司，成稿写成母公司。

`pass` —— 归属对；或原文本身就用了同一个泛称；或成稿用的是原文里出现过的同指称呼
（全名 ↔ 简称、「美国太空军」↔「Space Force」）。

## 你可以读什么（证据范围写死）

- 成稿：`out/<runId>/c<clusterId>.json`。
- **整簇全部原文**：`out/_data/<dataset>/content/<articleId>.txt`——归属正确与否要在全簇里核。

## 判定口径

**这一轴你的召回天生很低，宁可漏报，也别造一条假旗标。** 判不准就 `pass`，`reason` 写明为什么判不准。
（2026-09-18 起这条就写在慢档守则里：主体/日期搬错这类错很难看出来，硬猜出来的 `fail` 比漏报更贵。）

只判归属，不判这个动作本身是否存在（那是 `invented-fact`）、不判程度（那是 `strength-distortion`）。

正确的归属在簇内**别处**有、只是不在被引的那句里 → 本轴 `pass`，那是 `citation-support` 的 `fail`：

> **在簇内别处有原文、只是不在被引句里的东西，一律归 `citation-support`，不归本轴。**
> 2026-09-20 那轮把这一类记成了编造类缺陷，72 条旗标里只有约 22% 是读者可见的错。

## 输出

一簇一个文件，路径：

```
out/<runId>/verdicts/actor-swap-c<clusterId>.json
```

```json
{
  "axis": "actor-swap",
  "cluster": 7,
  "runId": "exec-support-mech@prod-0919#2",
  "promptId": "<派你的指令给出的值，照抄>",
  "judgements": [
    { "ref": "b1s5", "label": "fail", "reason": "这句引语原文出自空军部长，成稿挂给了太空军司令" },
    { "ref": "b1s6", "label": "pass" }
  ],
  "packDefects": []
}
```

- `ref` = `b<块序号>s<句序号>`，两个序号都从 1 起，按成稿 `blocks[]` / `sentences[]` 的原顺序。
- `label` 只有 `pass` / `fail`，**不允许** `unsure` / `partial` / 空值。
- `reason`：`fail` 必填一句，写明**原文是谁、成稿写成了谁**；`pass` 可省。
- `packDefects`：材料本身的问题写进这里。
- `promptId` 由指令给出，照抄；不要自己算、不要留空。
- **每一句都要有一条判定**，一条不落。`verdict` 为 `not_a_single_event` 的簇不用判、不用落文件。
