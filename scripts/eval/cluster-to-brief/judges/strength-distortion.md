# judge: strength-distortion（强度或方向失真）

一轴一份规格，本文件自足：读完它 + 指令点名的文件就能判完，不需要再看仓库里任何别的东西。
本文件的哈希就是 `promptId`。**改本文件等于换一把尺，旧判定作废**（`collect-verdicts.mjs` 拿退出码拦）。

## 判什么（二元）

对成稿的每一句：**方向或强度被实质性地改了，读者会形成明显偏离原文的印象？**

`fail` 的典型形状：

- **比较关系反了**：31 人死亡的袭击被写成「超过」（surpasses）另一起 101 人死亡的袭击。
  数字两个都在簇里、都没写错，错的是把它们的大小关系说反了——这一条是本轴的样板案例。
- 方向反了：原文是下降，成稿写成上升；原文是否认，成稿写成承认；漏掉否定词。
- 强度拔高：原文「可能」「据称」「计划中」，成稿写成已发生、已确认、已完成。
- 量级拔高：原文「数十」写成「数百」；「部分地区」写成「全国」；「一名官员表示」写成「官方宣布」。
- **消息源被剥掉**：原文写「X 说」「据 Y 简介」「据称」，成稿去掉归属、当成事实陈述。
  这**不算合理省略**——省掉的恰恰是读者判断可信度的依据，判 `fail`。

`pass` —— 方向与量级都与原文一致；或只是措辞更简洁（合理省略细节、合并同类项、明示的判断语）。
四舍五入、「约 1.2 万」代替「11,984」这类算 `pass`。

## 你可以读什么（证据范围写死）

- 成稿：`out/<runId>/c<clusterId>.json`。
- **整簇全部原文**：`out/_data/<dataset>/content/<articleId>.txt`。
  比较类失真必须把被比较的**两个**数字都在原文里找到再判，否则你判的是自己的记忆。

## 判定口径

只判方向与强度，不判这个事实是否存在（`invented-fact`）、不判归属（`actor-swap`）、
不判连接（`invented-relation`）。数字本身写错了但方向对 → 归 `invented-fact`，本轴 `pass`。

正确的强度在簇内**别处**有、只是不在被引的那句里 → 本轴 `pass`，那是 `citation-support` 的 `fail`：

> **在簇内别处有原文、只是不在被引句里的东西，一律归 `citation-support`，不归本轴。**
> 2026-09-20 那轮把这一类记成了编造类缺陷，72 条旗标里只有约 22% 是读者可见的错。

## 输出

一簇一个文件，路径：

```
out/<runId>/verdicts/strength-distortion-c<clusterId>.json
```

```json
{
  "axis": "strength-distortion",
  "cluster": 7,
  "runId": "exec-support-mech@prod-0919#2",
  "promptId": "<派你的指令给出的值，照抄>",
  "judgements": [
    { "ref": "b1s4", "label": "fail", "reason": "31 死写成「超过」101 死那起，大小关系反了" },
    { "ref": "b1s5", "label": "pass" }
  ],
  "packDefects": []
}
```

- `ref` = `b<块序号>s<句序号>`，两个序号都从 1 起，按成稿 `blocks[]` / `sentences[]` 的原顺序。
- `label` 只有 `pass` / `fail`，**不允许** `unsure` / `partial` / 空值。判不准就 `pass` 并说明。
- `reason`：`fail` 必填一句，写出**原文的方向/量级**与**成稿的方向/量级**；`pass` 可省。
- `packDefects`：材料本身的问题写进这里。
- `promptId` 由指令给出，照抄；不要自己算、不要留空。
- **每一句都要有一条判定**，一条不落。`verdict` 为 `not_a_single_event` 的簇不用判、不用落文件。
