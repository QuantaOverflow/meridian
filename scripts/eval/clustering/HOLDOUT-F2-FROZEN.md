  0.015 的带里，无信号

所以「在调参集上最优」不足以定档。

## 候选（参数全部锁定，holdout 上不做任何调参）

### A — 生产现状（基线）

```
预处理   emb L2 归一化
UMAP     n_components=5, n_neighbors=15, min_dist=0.1, metric='cosine'
HDBSCAN  min_cluster_size=3, min_samples=1, metric='euclidean',
         cluster_selection_method='eom', cluster_selection_epsilon=0.35
种子     random_state ∈ {42, 1, 2026, 7, 99}，报 5 种子均值与带
```

### B — 不降维（主候选）

```
预处理   emb L2 归一化
距离     余弦距离矩阵（1 − cos），不降维
HDBSCAN  min_cluster_size=3, min_samples=1, metric='precomputed',
         cluster_selection_method='eom', cluster_selection_epsilon=0.06
种子     无（不过 UMAP 即无随机性），单次即定论
```

> `eps` 0.35 → 0.06 **不是「调小」**：两者是不同空间的绝对阈值。A 的 eps 作用在 UMAP 输出的
> 欧氏空间，B 的作用在原始余弦距离上（全域范围仅 0–0.32）。不可比。

### C — B + 嫌疑标记（只标记，不删除）

```
在 B 的输出上，对每个簇算：
  实体核心比 = 被 ≥50% 文章共享的 key_entities 占该簇实体的比例（不加权）
  跨源数     = 簇内不同 source_id 的个数
判为嫌疑：实体核心比 ≤ 0.242 且 跨源数 ≤ 3
嫌疑簇不删除，只在输出里标记
```

> C 的划分与 B 逐字相同，所以 C 的 ARI/B³ 必然等于 B。C 只由 H4 单独判定。
> 「只标记不删」是刻意的：调参集上实测簇级硬门是全有全无，判错一次整簇归零，
> 曾把 8 篇的 NASA 望远镜簇、11 篇的阿富汗驱逐簇整个抹掉。

## 判据（跑前写死）

| # | 判据 | 通过条件 |
|---|---|---|
| **H1** | B 的 ARI 高于 A | 事件层与主题层**两层同向为正** |
| **H2** | B 的组完整率不塌 | `完整率(B) ≥ 完整率(A) − 0.03` |
| **H3** | B 的目标事件交付率 | ≥ 95%（目标事件 = 金标里 ≥3 篇的事件；交付 = 该事件有 ≥2 篇落进同一个簇） |
| **H4** | C 的嫌疑标记准不准 | 被标为嫌疑的簇中，真·题材凑堆（不对应任何 ≥2 篇金标事件的簇）占比 ≥ 60% |

**H1–H3 全过 = B 可以落生产代码。** 任一条不过即不过，不许换指标重判。
H4 独立判定，只决定 C 那层嫌疑标记要不要一起上，不影响 H1–H3 的结论。

指标定义与实现：`full-score.ts`（ARI 为主指标，B³-P/R 为诊断；噪声 `-1` 展开成单元素组）。
打分命令：`tsx full-score.ts --window=F2 [--topic] <labels...>`

## 标注规范

照 `rubric.md`，特别是：
- 第一节：判的是「同一个 happening」，不是主题 / 实体 / 故事线
- 三·五节：主题层判据（同一冲突/同一持续局势归一主题，粒度以「够写简报一段」为准）
- 第五节 + 「F2 起改为全覆盖划分」：窗口内每一篇都要有归属，杂讯记为**各自的**单元素组

流程：三个标注者独立通读全部 1252 条 → 成员级多数决合并（≥2 人认为两篇同组则连边，取连通分量）
→ codex 独立复核 → 按复核结论修订 → 机械校验。

**标注过程中不得查看任何聚类输出。** 调参集那轮有过教训：曾按算法的簇内容单向补入 13 篇金标，
只对称补回 2 篇，等于用算法结果修正尺子。这轮禁止。
