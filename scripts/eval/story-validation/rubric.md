# 故事判定标注规范（金标 rubric）

人照此规范标注「一个产出故事是否成立」，用来评 story-validation 这一环——无论它由哪种架构产出（整簇送 LLM、几何切细、几何候选 + LLM 判官）。方法论依据见 `docs/eval-playbook.md`。

> **核心原则**：简报的单位是「**发生了什么**」。一个故事成立 = 该故事内有 **≥2 篇文章报道同一个具体发生**。
>
> 标的是「这条产出是不是一个真实事件」——**不是**这个事件重不重要。一件无聊小事被两家媒体报道，故事成立；一个重大议题的三篇泛论分析，故事不成立。

**「≥2 篇」不要求跨信源**——同一家媒体对同一发生的多篇报道同样算数（2026-08-20 用户拍板）。

---

## 1. 判定值

| 值 | 定义 |
|---|---|
| **correct** | 有 ≥2 篇报道同一个具体发生，且没有混入别的发生 |
| **umbrella** | **有**真核（≥2 篇确实同一发生），但**另外**混进了别的发生 |
| **wrongPair** | **压根没有**真核——成员是题材/地域/人物相似的不同发生被硬凑 |
| **borderline** | 判不下去，需要补政策。**单列，不许硬塞进任一边** |

`umbrella` 与 `wrongPair` 必须分开统计：两者的修法完全不同。实测（2026-08-20，7 个架构臂 244 条）：

- **让 LLM 在整簇里自由划**的臂，错误 86% 是 `umbrella`
- **先做几何预分组**的臂，`umbrella` 基本消灭，错误 80–100% 是 `wrongPair`

即几何预分组解决「混进别的发生」，代价是把语义近但非同一发生的两篇送到判官面前。

---

## 2. 算「同一个发生」

### 2.1 同一条主线的不同阶段 / 后续进展

学生抗议 → 政府谈判 → 取消考试 → 宣布第二阶段 = **一个**故事。

判据是**有推进**：有起点、有进展、有结果。

### 2.2 同一件事的不同方 / 不同角度

自杀事件 与 尸检结果 = 一个；争议 与 当事人回应 = 一个。

### 2.3 同一项目 / 事务的不同侧面

皇岗口岸改造评论 与 该口岸压力测试演练 = 一个。

### 2.4 该事件自身的汇总 / 转录稿，算合法成员

```
《Face the Nation 8/16 期》
  622428  嘉宾 Chris Rabb 访谈转录
  622429  嘉宾 Don Bacon 访谈转录
  622430  嘉宾 Andy Beshear 访谈转录
  622432  8/16 当期节目综述        ← 是这期节目本身的一部分，算成员
```

## 3. 不算（三条收紧，2026-08-21 定）

### 3.1 主线的锚点必须是「事件」，不是「人物」或「机构」

```
❌ 判 wrongPair
《Trump aide Natalie Harp: 'unhealthy' relationship and secret travel》
  625085  兄长质疑她与总统的"不健康"关系
  625616  旧视频被翻出，她被起了刻薄绰号
  630204  "梅拉尼娅去哪了"——Harp 总不离总统左右
```

三篇都关于同一个人，但**没有推进**——是媒体在同一人身上做的三个静态侧面，不是一件事的不同时刻。

**判据**：问「这几篇是不是同一件事的不同时刻/侧面」，**不要**问「是不是关于同一个人」。

理由：人物侧写堆一起没有事件内核，标题只能写成「某人的争议」——那正是伞。

### 3.2 对同一底层事件的独立评论 = 不同发生

「A 评论了 X」与「B 评论了 X」是两个发生（例：Fox 主持人与 John Oliver 各自评论同一事）。

**例外**：若评论本身引发了有推进的事件（被回应、成争议、上新闻），则该「评论争议」本身是一个发生。

### 3.3 综述分两类

- **算成员**：该事件自身的汇总 / 转录（见 §2.4）
- **不算成员，计为混入**：泛论该议题的分析稿

```
❌ 判 umbrella
《West Bank — Settler violence and military raids intensify》
  真核  616541 军队围困民宅 / 616543 Qusra 居民断水断粮
        618383 UN Albanese 表态 / 633746 每周综述
  混入  618994 定居者搭新哨点        ← 另一个发生
        633749 定居者儿童袭击救护车  ← 另一个发生
        617768《什么能阻止定居者袭击？》← 泛论分析，不报道任何具体发生
```

### 3.4 其余

- 两个独立发生并列 = wrong。例：两部**不同电影**各自的票房
- 题材/地域/人物相似但非同一发生 = `wrongPair`。例：李家超施政评论 vs 国债期货上市（同为「香港经济评论」不算同一发生）

## 4. 标注纪律

- **一个领域专家定标准**，不要委员会平均。
- 每条写一句 `reason` 说明判据——既是复核依据，也是未来 few-shot 素材。
- **判类别，不打分。**
- **按成员集去重再判**：同一成员集在不同架构臂必然同判。244 条实测去重成 113 个唯一成员集，省掉一半重复劳动，也杜绝同集异判。
- 标注者**看不到被评方案的自述理由**。实测多次出现「动作对但 reason 是编的」——模型把某篇文章说成完全不相干的内容，动作却侥幸正确。**reason 不能当判定依据。**

---

## 5. 已知的口径敏感处（还没定死）

以下几类改判会移动读数，遇到时先记 `borderline` 再回来补政策：

1. **同一场运动的「特写」与「具体呼吁」**是否算同一发生（实测 `U46`：CJP 运动学校特写 vs Dipke 呼吁入读公校）
2. **两位政治人物就同一恩怨的各自发言**是否同属一条互怼主线（实测 `U65`）

---

## 6. 不要用机械尺代替人工判定

`event_recall2.mjs` 打印的「故事精度」是**宽口径**（故事内有真核即算对），会系统性高估含伞的臂。2026-08-20 实测：生产现行架构宽口径 75%、人工严口径 **41.7%**，差距全在「真核 + 一堆别的事」的大伞上。

**报精度必须注明口径。**
